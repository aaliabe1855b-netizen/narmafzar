# NEON CAD — نرم‌افزار طراحی و آماده‌سازی تابلو نئون

یک اپلیکیشن وب کامل برای طراحی تابلو نئون: از طرح دیجیتال تا فایل آماده ساخت.
به‌صورت **یک Cloudflare Worker تک‌فایلی** (`worker.js`) ارائه می‌شود — کل HTML/CSS/JavaScript داخل همان فایل است و **تمام پردازش‌های هندسی در سمت مرورگر** انجام می‌شود (بدون سرور جانبی، بدون وابستگی به CDN).

> طراحی معماری، ساختار داده و الگوریتم‌ها پیش از کدنویسی در [docs/DESIGN.md](docs/DESIGN.md) مستند شده است.

### نکتهٔ کلیدی: اصلاح هندسی، نه گرد کردن عدد

اگر طول مسیر `83.2 cm` باشد، نرم‌افزار عدد را به `85 cm` گرد **نمی‌کند**؛ بلکه **هندسه را واقعاً اصلاح می‌کند**:

- انتهای آزاد → تغییر مقیاس یکنواخت حول مرکز ثقل (شکل حفظ می‌شود)
- انتهای قفل (اتصال به زنجیره) → تغییر ضریب عمودی رأس‌های داخلی نسبت به وتر با جست‌وجوی دو‌دودویی تا طول واقعی دقیقاً `85 cm` شود

طول هدف = `ceil(L / 2.5) × 2.5` (همیشه به بالا — هیچ تکه‌ای کوتاه‌تر از اندازهٔ لازم بریده نمی‌شود).
در نتیجه **همهٔ نقاط START و END واقعاً روی Cutting Pointهای فیزیکی 2.5cm نئون می‌نشینند.**

## استقرار روی Cloudflare Worker + اتصال خودکار GitHub

### ۱. ساخت Worker از روی مخزن GitHub

1. به [Cloudflare Dashboard](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → **Import a repository** بروید.
2. مخزن GitHub این پروژه (`narmafzar`) را انتخاب کنید (در صورت نیاز ابتدا GitHub را به Cloudflare وصل کنید — *Workers Builds*).
3. Cloudflare فایل [`wrangler.toml`](wrangler.toml) را به‌صورت خودکار تشخیص می‌دهد:
   - **Framework preset:** None
   - **Build command:** *(خالی — نیاز به build نیست)*
   - **Deploy command:** `npx wrangler deploy`
4. روی **Save and Deploy** بزنید. آدرس عمومی شما `https://narmafzar.<account>.workers.dev` خواهد بود.

### ۲. استقرار خودکار با هر تغییر

از این پس **هر push به مخزن، به‌صورت خودکار در Cloudflare مستقر می‌شود**؛ یعنی تغییرات مستقیماً از GitHub داخل Cloudflare ذخیره و انتشار می‌یابند. وضعیت هر استقرار در تب **Deployments** همان پروژهٔ Worker دیده می‌شود.

### ۳. اجرای محلی با Wrangler (اختیاری)

```bash
npm install
npx wrangler dev      # اجرای محلی Worker
npm run deploy        # استقرار دستی
```

## تست‌ها

```bash
npm run check
```

- تطابق دقیق جدول نمونه (125 / 82.5 / 47.5 → 50 / 33 / 19 → A-B / B-C / C-D)
- اصلاح هندسی طول (آزاد و قفل) → طول واقعی روی گام برش

- محاسبهٔ برق (2.55m × 10W/m = 25.5W → پیشنهاد 40W با ضریب 80%)

## محدودیت‌های MVP (نقشهٔ راه)

- ویرایشگر دستگیره‌های Bezier (کشیدن دسته‌ها) — در نسخه‌های بعدی
- Import فایل‌های SVG دارای `transform` پیچیده (فعلاً هندسه بدون transform و با جاگذاری خودکار در تابلو)
- الگوریتم‌های پیشرفته‌تر پرت (Best-Fit / جست‌وجوی ترکیبی)

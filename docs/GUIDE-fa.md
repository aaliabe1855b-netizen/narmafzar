# راهنمای کامل NEON CAD — به زبان فارسی

> این راهنما دقیقاً همان متنی است که داخل نرم‌افزار با دکمهٔ **HELP / راهنما** (یا کلید **F1**) باز می‌شود.
> نسخهٔ داخل نرم‌افزار در اولین ورود نیز به‌صورت خودکار نمایش داده می‌شود.

---

## ۱. گردش کار کلی — از طرح تا تابلوی واقعی

این نرم‌افزار طرح دیجیتال شما را به «مسیر واقعی نئون» تبدیل می‌کند، طول‌ها را از نظر هندسی اصلاح می‌کند تا با نقاط برش واقعی نئون هم‌خوان شوند، و در نهایت فایل آمادهٔ ساخت تحویل می‌دهد:

**Design → Neon Path → Geometry Fix (2.5cm) → Cut Points → Cut List → Power → CUT FILE**

### مراحل پیشنهادی قدم‌به‌قدم

1. ابعاد تابلو را در **PROPERTIES** وارد کنید (مثلاً عرض 200 و ارتفاع 100 سانتی‌متر).
2. طرح را بکشید (Pen / Line / Bezier) یا با **TRACE IMAGE** از روی عکس بسازید یا از منوی **EXAMPLES** یک نمونه حرفه‌ای شروع کنید.
3. در حالت **AUTO MODE** نرم‌افزار خودکار شماره‌گذاری (NEON 01...) می‌کند و طول هر مسیر را **هندسیاً** اصلاح می‌کند تا مضرب 2.5 سانتی‌متر شود.
4. جدول برش پایین صفحه را بررسی کنید (شماره، طول، تعداد برش، شروع، پایان).
5. دکمهٔ **CHECK DESIGN** را بزنید و همهٔ هشدارها را برطرف کنید.
6. برای ساخت تابلو، **CUT DXF** (فایل برش‌دهنده) و **PRINT / PDF** (برگهٔ ساخت) را دانلود کنید.
7. متراژ و توان لازم را از تب **MATERIALS & POWER** بردارید و منبع تغذیه مناسب بخرید.

> **نکتهٔ طلایی:** نرم‌افزار هیچ‌وقت طول را «فقط گرد نمی‌کند». اگر مسیری 83.2 سانت باشد، هندسهٔ آن را طوری تغییر می‌دهد که طول واقعی به 85 سانت (34 × 2.5) برسد و شکل تا حد امکان حفظ شود. به همین دلیل همهٔ نقاط START و END روی نقاط برش واقعی نئون می‌نشینند.

## ۲. نوار بالا (Top Bar)

| کنترل | کاربرد |
|---|---|
| **نام پروژه** | نام طرح برای ذخیره و خروجی‌ها. تایپ کنید و Enter بزنید. |
| **AUTO MODE / MANUAL MODE** | در حالت خودکار، شماره‌گذاری، اصلاح طول‌ها و ساخت جدول برش بعد از هر تغییر انجام می‌شود. در حالت دستی، همه‌چیز تحت کنترل شماست. |
| **Undo / Redo** | بازگردانی یا تکرار آخرین تغییرات (Ctrl+Z / Ctrl+Y). |
| **CHECK DESIGN** | بررسی کامل طرح قبل از خروجی — بخش ۹. |
| **PRINT / PDF** | برگهٔ ساخت: جدول برش + محاسبهٔ برق + پرت رول + نقشه. در پنجرهٔ چاپ مرورگر Save as PDF را بزنید. |
| **SVG / DXF / PNG / CSV / JSON** | خروجی‌های معمول طرح (بخش ۸). CSV همان جدول برش است. |
| **CUT DXF / CUT SVG** | **مهم‌ترین خروجی برای ساخت:** فایل «طرح دوبل» برای برش‌دهنده (بخش ۸). |
| **TRACE IMAGE** | تبدیل خودکار عکس به مسیر نئون — بخش ۷. |
| **EXAMPLES** | نمونه‌های حرفه‌ای: تابلوی کافه (دایره + نوشتهٔ فارسی نئون)، گالری اشکال، دموی زنجیره‌ای جدول برش. |
| **SAVE / OPEN** | ذخیره و باز کردن پروژه داخل همین مرورگر (بخش ۱۱). |
| **IMPORT** | وارد کردن فایل SVG یا JSON. |
| **NEW** | شروع پروژهٔ خالی. |
| **HELP** | همین راهنما. کلید F1 هم آن را باز می‌کند. |

## ۳. ابزارها (TOOLS — سمت چپ)

### ابزارهای ترسیم

- **Select (انتخاب)** — کلیک روی مسیر = انتخاب؛ کشیدن = جابه‌جایی. رأس‌ها (نقطه‌های سفید) را بکشید تا شکل عوض شود. Shift = انتخاب چندتایی.
- **Pen (قلم)** — کلیک‌کلیک برای خط شکسته. `Enter` یا دوکلیک = پایان، `Esc` = لغو.
- **Line (خط)** — دو کلیک: شروع و پایان یک خط صاف.
- **Bezier (منحنی)** — مانند Pen کلیک کنید؛ هنگام پایان به‌صورت خودکار به منحنی‌های نرم تبدیل می‌شود — ایده‌آل برای اشکال خم‌دار نئون.
- **Text (متن)** — یادداشت روی طرح (نئون نیست و در جدول برش نمی‌آید). برای متن نئونیِ واقعی از TRACE IMAGE استفاده کنید.

### ابزارهای ویرایش

- **Snap Grid** — چسباندن نقاط به گرید (اندازه در PROPERTIES).
- **Channel** — نمایش «طرح دوبل»: دو خط موازی اطراف مسیر = جایی که برش‌دهنده می‌برد و ریسه می‌نشیند.
- **Snap Lengths** — اصلاح هندسی طول همهٔ مسیرها روی گام برش (در AUTO خودکار است).
- **Reverse** — تغییر جهت مسیر انتخاب‌شده.
- **Delete** — حذف مسیر انتخاب‌شده.

### اندازه‌گیری و تقسیم

- **Split** — کلیک روی مسیر → تقسیم دقیقاً در نزدیک‌ترین نقطهٔ برش واقعی (مضرب 2.5 سانت از ابتدا).
- **Measure** — دو کلیک؛ فاصلهٔ دقیق بر حسب سانتی‌متر.

---

## ۴. بوم طراحی (CANVAS — وسط صفحه)

- **زوم:** اسکرول موس · **جابه‌جایی نما:** Space+درگ یا دکمهٔ وسط موس · **مختصات:** گوشهٔ پایین-چپ (سانتی‌متر، مقیاس واقعی).
- **گرید:** خطوط ریز = 1 سانت، درشت = 10 سانت. کادر تابلو = ابعاد PROPERTIES.

### برچسب‌ها روی طرح

- **NEON 01, NEON 02, ...** — شمارهٔ هر مسیر.
- **START 01 / END 01** — شروع (سبز) و پایان (قرمز) هر قطعهٔ قابل برش.
- **A , B , C , ...** — نقاط اتصال/انتهای آزاد؛ همین حروف در جدول برش می‌آیند.

---

## ۵. ویژگی‌ها (PROPERTIES — سمت راست)

### ابعاد تابلو
- **Width / Height** — عرض و ارتفاع تابلو بر حسب سانتی‌متر (مقیاس واقعی).

### پروفایل نئون
| فیلد | معنی |
|---|---|
| Saved profiles | انتخاب پروفایل ذخیره‌شده (بخش ۱۰). |
| Neon Width | عرض ریسه به میلی‌متر (مثلاً 8). |
| Cutting Interval | **گام برش** به سانتی‌متر (پیش‌فرض 2.5). طول‌ها روی مضرب‌های این عدد هندسیاً اصلاح می‌شوند. |
| Minimum Bend Radius | حداقل شعاع خم نئون (mm) — تیزتر از این = هشدار. |
| Voltage | ولتاژ ریسه (مثلاً 24V). |
| Power per meter | مصرف هر متر (W/m، مثلاً 10). |
| Roll Length | طول هر رول (سانتی‌متر، مثلاً 500). |

### تنظیمات برش و برق
| فیلد | معنی |
|---|---|
| Max Piece Length | حداکثر طول هر تکه؛ مسیرهای بلندتر خودکار تقسیم می‌شوند. |
| Min Path Spacing | حداقل فاصلهٔ بین دو مسیر. |
| PSU Safety Factor | ضریب اطمینان منبع (٪، پیش‌فرض 80 = بیست ٪ هدروم). |
| PSU Capacity | توان منبع موجود (وات) برای مقایسه؛ 0 = پیشنهاد خودکار. |
| Grid Snap | گام چسباندن نقاط هنگام ترسیم. |
| Node Tolerance | تلورانس یکی‌شدن انتهای دو مسیر به‌عنوان اتصال. |
| Cutting Channel Width | عرض کانال برش (mm، پیش‌فرض 10 = نئون 8 + خلاصی 2). |
| Include centerline | افزودن مرکزخط به فایل برش‌دهنده. |

### پنل مسیر انتخاب‌شده
نام، طول هندسی، طول اصلاح‌شده، تعداد قطعات/برش‌ها، نقاط شروع/پایان + دکمه‌های **Reverse / Lock Start / Lock End / Snap Length / Delete**.

---

## ۶. جدول برش و مواد (پایین صفحه)

### تب CUT LIST
| ستون | معنی |
|---|---|
| شماره | شمارهٔ قطعه (روی طرح = START 01 / END 01). |
| طول | طول واقعی قطعه (سانتی‌متر، مضرب گام برش). |
| تعداد برش | تعداد واحدهای 2.5cm داخل قطعه (طول ÷ 2.5). |
| شروع / پایان | حرف نقطهٔ شروع/پایان (مثل A و B). |

دکمهٔ **PRINT / PDF this table** = برگهٔ ساخت کامل.

### تب MATERIALS & POWER
**TOTAL NEON** (متراژ کل) · **POWER** (توان کل = متراژ × W/m) · **POWER SUPPLY** (پیشنهاد منبع با ضریب اطمینان + جریان آمپر) · **ROLLS & WASTE** (تعداد رول و پرت).

### تب ROLLS & WASTE
هر نوار = یک رول؛ رنگ‌ها = قطعات چیده‌شده، خاکستری = پرت. الگوریتم First-Fit-Decreasing پرت را حداقل می‌کند.

---

## ۷. تبدیل عکس به نئون (TRACE IMAGE)

1. دکمهٔ **TRACE IMAGE** → انتخاب عکس (PNG/JPG/WEBP/GIF/BMP).
2. پیش‌نمایش خطوط قرمز = مسیرهایی که ساخته می‌شود.
3. اسلایدرها را تنظیم کنید و **Add to design** بزنید.

| کنترل | کاربرد |
|---|---|
| Threshold | مرز سیاه/سفید. |
| Detail | ریزبینی (کمتر = نرم‌تر). |
| Min stroke | حذف خط‌های نویزِ کوتاه (2–4 سانت). |
| Invert | شکل روشن روی پس‌زمینهٔ تیره. |
| Smoothing | تبدیل به منحنی‌های نرم (پیشنهادی: روشن). |

> بهترین نتیجه با عکس‌های پرکنتراست سیاه‌وسفید. برای متن نئونی: متن را سیاه روی سفید بنویسید و عکسش را تریس کنید (نمونهٔ «نئون» در تابلوی کافه با همین روش ساخته شده).

---

## ۸. فایل برش‌دهنده (CUT DXF / CUT SVG) و خروجی‌ها

### طرح دوبل — فایلی که به برش‌دهنده می‌دهید
ریسه داخل «کانال» (شیار) می‌نشیند؛ ماشین باید **دو خط موازی** اطراف مسیر را ببرد:

- **CUT DXF / CUT SVG** دقیقاً همین طرح دوبل را می‌سازند؛ فاصلهٔ دو خط = Cutting Channel Width.
- لایه‌ها: `CUT1` و `CUT2` (+ `CENTER` در صورت تیک Include centerline). واحدها cm، مقیاس 1:1.
- با ابزار **Channel** قبل از خروجی، خطوط برش را روی طرح ببینید.

### بقیهٔ خروجی‌ها
| دکمه | محتوا |
|---|---|
| SVG / DXF | نقشهٔ کامل طرح با شماره‌ها و برچسب‌ها (مقیاس واقعی). |
| PNG | عکس با وضوح بالا. |
| CSV | جدول برش برای اکسل + جمع کل + برق. |
| JSON | کل پروژه (باز کردن دوباره / ارسال به همکار). |
| PRINT / PDF | برگهٔ ساخت: جدول + متریال + برق + پرت + نقشه + امضا. |

### گردش ساخت واقعی
1. طراحی + CHECK DESIGN
2. **CUT DXF** ← برش‌دهنده (شیار کانال روی صفحه)
3. **PRINT / PDF** ← برگهٔ ساخت تیم
4. بریدن ریسه طبق جدول (شروع/پایان روی نقاط برش واقعی 2.5cm)
5. مونتاژ ریسه داخل کانال + سیم‌کشی A/B/C + نصب منبع پیشنهادی

## ۹. بررسی نهایی (CHECK DESIGN)

| پیام | معنی | راه‌حل |
|---|---|---|
| LEN | طول روی گام برش نیست و اصلاح هندسی ممکن نبود. | شکل را کمی تغییر دهید یا قفل‌ها را باز کنید → Snap Lengths. |
| SPACE | دو مسیر از حداقل فاصله نزدیک‌ترند. | جابه‌جایی یا کم‌کردن Min Path Spacing. |
| BEND | گوشه تیزتر از حداقل شعاع خم. | گوشه را نرم کنید (Bezier). |
| OPEN | مسیر ناقص/کوتاه‌تر از یک گام. | تکمیل یا حذف. |
| JOIN | انتهای دو مسیر تقریباً چسبیده ولی وصل نیست. | روی هم بکشید یا فاصله دهید. |
| PSU | توان کل از ظرفیت منبع بیشتر است. | منبع بزرگ‌تر. |
| LONG | مسیر بلندتر از حداکثر طول تکه (تقسیم شده). | طبیعی؛ اتصال‌ها را چک کنید. |
| GRID | طول تکه روی گام 2.5 ننشسته. | Snap Lengths. |

سبز = «All checks passed» = آمادهٔ خروجی و ساخت.

## ۱۰. پروفایل نئون

1. مشخصات ریسه را در PROPERTIES پر کنید → **Save Profile**.
2. در پروژه‌های بعدی از **Saved profiles** انتخاب کنید.
3. **Delete Profile** برای حذف.

مثال: `Neon Flex 8mm` — عرض 8mm، 24V، برش هر 25mm، حداقل خم 30mm، 10W/m، رول 5m.

## ۱۱. ذخیره‌سازی و میان‌برها

- **SAVE / OPEN** — ذخیره در مرورگر (localStorage). برای طرح‌های مهم حتماً **JSON** خروجی بگیرید (پاک‌کردن دادهٔ مرورگر = حذف پروژه‌ها).
- **IMPORT** — باز کردن فایل SVG یا JSON.

| کلید | کار |
|---|---|
| V / P / L / B / T / S / M | ابزارها |
| Enter یا دوکلیک | پایان ترسیم |
| Esc | لغو / بستن پنجره / بازگشت به Select |
| Delete | حذف انتخاب |
| Ctrl+Z / Ctrl+Y | Undo / Redo |
| Space+درگ | جابه‌جایی نما |
| F1 | راهنما |

## ۱۲. نکات و عیب‌یابی

**چرا طول‌ها کمی عوض می‌شوند؟** چون طول واقعی مسیر هندسیاً روی مضرب 2.5 اصلاح می‌شود تا با نقاط برش کارخانه‌ای ریسه هم‌خوان باشد (شکل تا حد امکان حفظ می‌شود).

**چرا «تعداد برش» مهم است؟** تیم برش با تعداد واحد 2.5cm کار می‌کند (مثلاً 50 یعنی 125 سانت).

**منبع چند وات؟** از تب MATERIALS & POWER مقدار پیشنهادی را ببینید (با ضریب اطمینان 80٪).

**تریس تمیز نیست؟** Threshold را جابه‌جا، Detail را کم، Min stroke را زیاد کنید؛ عکس پرکنتراست‌تر استفاده کنید.

**AUTO یا MANUAL؟** AUTO برای سرعت و اطمینان (همه‌چیز خودکار). MANUAL برای کنترل دقیق (قفل‌ها، تقسیم، جهت). در MANUAL هم دکمه‌های Snap Lengths در دسترس است.

> **شروع سریع:** منوی EXAMPLES → «Cafe Sign» — یک تابلوی آماده با دایره، نوشتهٔ فارسی «نئون» و چند شکل؛ همان را ویرایش کنید یا از روی آن یاد بگیرید.
